# Pre-v1.0.0 Archive

This directory contains planning notes, implementation snapshots, test reports,
and diagnostic scripts created before the v1.0.0 baseline.

These files are retained for historical context only. They do not describe the
current CLI, supported providers, security guarantees, or formal test coverage.
Use the active documents in the repository root for current information:

- `README.md`
- `CURRENT_STATUS.md`
- `ARCHITECTURE.md`
- `TESTING.md`
- `SECURITY.md`
- `CHANGELOG.md`
- `ROADMAP.md`
- `USAGE.md`

Do not treat historical API test reports as evidence that Syzzz Code currently
supports a provider end to end. Some reports exercised an external Claude CLI,
and some scripts read the local user configuration or made real network calls.
